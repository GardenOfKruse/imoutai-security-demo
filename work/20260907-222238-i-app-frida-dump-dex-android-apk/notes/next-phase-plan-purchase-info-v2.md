## 1. 已有情报（本轮 App 端分析迁移）

- 风控组件：Everisk 风控（行为遥测：LoginChecker 采集触摸/传感器序列，scene=login）、设备指纹绑定（32-hex deviceKey 跨会话稳定、`clips_*` 三个设备 token）、native 派生 RSA 私钥（`CryptoUtil.getPrivateKey`）。
- 签名体系（App 端）：vcode `md5(deviceKey+mobile+timestamp)`（已 15/15 验证）；请求头经 okhttp 拦截器集中注入。
- 目标接口在 **H5 域**（`h5.moutai519.com.cn`），与 App 端（`app.moutai519.com.cn`）前端独立 → **H5 签名链必须先逆向**（Phase 0），否则无法构造合法签名请求。
- App 端下单链路接口参考：`/xhr/front/trade/order/standard/compose|submit`、`/xhr/front/mall/reservation/add`。

## 3. 低频执行 Runbook（可多次，单进程串行）

### 3.1 参与角色
- 操作员 1 名（执行 + 监控）；客户侧对接人 1 名（窗口内可联系，紧急止损）。
- 登录采用**人工参与**：测试账号短信验证码由操作员测试手机接收后人工输入，单次会话只使用一个测试账号；token 从客户端只读采集获得，不写撞库/验证码爆破逻辑。

### 3.2 环境与速率硬预算

| 项 | 上限 |
|---|---|
| 并发进程 | **1（单进程硬限制，见 AGENTS.md）** |
| 请求间隔 | ≥ 2 秒（即 QPS ≤ 0.5） |
| 总请求量 | ≤ 300（含全部用例） |
| 执行时长 | ≤ 30 分钟 |
| 窗口 | 除客户维护窗口 **06:00–06:15** 外均可执行；该窗口禁发 |
| 账号 | 客户提供的测试账号（本人实名，与真实用户隔离） |

### 3.3 用例矩阵（每次执行内顺序执行）

| 组 | 用例 | 请求数 | 观测点（风控能力判据） |
|---|---|---|---|
| A 基线 | 合法签名 + 合法 token 正常调用 purchaseInfoV2 | 5 | 基准响应时间/响应码；签名校验存在性 |
| B 签名强度 | 签名篡改/缺失/过期 timestamp（各 5） | 15 | 服务端是否拒绝、错误码语义、是否触发告警 |
| C 重放防护 | 同一签名请求原样重放（间隔 5s/30s/120s 三档） | 9 | nonce/时间窗/幂等防护是否存在 |
| D 设备绑定 | 更换 deviceKey/clips_ token 后调用 | 10 | 设备指纹校验强度（跨设备 token 是否被识别） |
| E 频控阈值 | 单进程匀速递增频率（从 1 req/5s 阶梯收紧至 1 req/2s 封顶） | ≤40 | 触发限流/验证码/封禁的阈值与形态 |
| F 下单链路 | 合法登录态下 compose/submit（**止步支付前**） | ≤5 | 下单接口的独立签名/风控信号 |
| G 恢复观察 | 停止后 15 分钟观察窗口 | 0 | 限流/封禁是否自动解除（用于报告风控策略推断） |

**单次执行建议 ≤ ~104 请求，远低于 300 预算**——风控能力判据来自"响应差异"，不来自压力；多次执行之间应保留低频间隔并重新检查预算。

### 3.4 中止条件（任一触发立即停止整轮）
1. 5xx 比例 > 1%；
2. 基准接口 p95 延迟较 A 组基线劣化 > 3 倍；
3. 出现限流误伤迹象（响应中带全局限流标识而非单账号）；
4. 客户对接人要求停止；
5. 到达 30 分钟时长或 300 请求预算。

### 3.5 执行前检查单（Pre-flight）
- [ ] P0-3 离线签名验证 PASS 证据归档
- [ ] 客户确认当前不在 06:00–06:15 维护窗口 + 对接人在线
- [ ] 测试账号可用、余额/状态正常
- [ ] 监控面板就绪（响应码/延迟/预算计数实时显示）
- [ ] 中止条件自动化（脚本内置，非人工判断）
- [ ] **进程数 = 1 确认**（driver/脚本启动参数复核，多进程即违门禁）
- [ ] 日志脱敏开关确认
